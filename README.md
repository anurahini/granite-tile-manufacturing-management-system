 🏭 Granite & Tile Manufacturing Management System

A web-based application developed to manage the operations of a Granite and Tile Manufacturing business.

 ✨ Features

- User Login and Registration
- Dashboard
- Product Catalog
- Different Tile Types
- Product Details and Images
- Product Comparison
- Inventory Management
- Supplier and Vendor Management
- Customer and Employee Management
- Purchase and Sales Orders
- Production Management
- Delivery, Invoice and Payment Management
- Damaged Product and Clearance Sale
- Light and Dark Theme
- Multi-Language Support
- AI Chatbot
 🧱 Tile Categories

- Wall Tiles
- Bathroom Tiles
- Floor Tiles
- Outdoor Tiles
- Kitchen Tiles
- Granite Slabs

Users can view product details such as price, colour, size, square feet and availability.

 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

```bash
npm install
npm run dev
